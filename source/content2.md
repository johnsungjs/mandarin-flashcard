你好，我做了一个HSK词汇练习网站

I've been learning Mandarin in my free time for the past few years.
One thing I keep struggling with is vocabulary.
If I don't review words regularly, I forget them surprisingly fast.
After trying different approaches, I found that flashcards work quite well for me.

However, many learning tools come with small frictions:
- Need to create an account
- Need to create decks manually
- Not comfortable to use on mobile
- No dark mode available (my eyes loves dark mode)

So I built a small side project called Mandarin Flashcard.

The idea is simple:

No login.

No setup.

No manual deck creation.

Open the website and start reviewing HSK vocabulary immediately.

From an engineering perspective, I also wanted to keep things simple.
Since user progress only matters on the current device, I decided not to add a backend or database.
The app is built with Next.js and stores progress locally in the browser.

Website:
https://mandarinflashcard.vercel.app

If you're also learning Mandarin, I'd love to hear your feedback and suggestions.
