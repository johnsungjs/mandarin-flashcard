你好，我做了网站可以帮我们提高HSK考试！
I just made a website that can help us improve HSK level with flashcard.

Over the past few years I've been learning mandarin in my free time, and during the learning period I face the same problem for over and over, I constantly forgot about vocabulary.

Then I discovered that memorizing vocab with flashcard works for me.

When using learning tools I encountered some friction such as:
- Required to create account
- Not mobile support
- Light theme
- Should add card manually

This Mandarin Flashcard tools solve those issue.

From engineering perspective, I am trying to using the least resource possible, so no need any backend service, no need database, everything happened on the client side with nextjs, but there is still a SEO support.

If you're looking to improve your HSK vocabulary as well, feel free to checkout this mandarin flashcard website.

I am also make this project open source, feel free to checkout the project repository:
https://mandarinflashcard.vercel.app

I am really opened to suggestion to improve this app so we can improve our mandarin skill together.
